# 使用指南

[English](user-guide.md) · **简体中文** · [文档目录](README.zh-CN.md)

## 连接与分组

点击“连接”或 Ctrl+N，先选择数据库类型，再填写参数，测试、保存并打开。已有连接右键可编辑、复制或删除。在“我的连接”中新建组，直接在左侧树输入名称；连接可拖入组或拖回根目录。删除组后，组内连接移回根目录。

各引擎使用专属图标，绿点表示连接已打开，灰点表示已关闭。双击已打开的连接或库可展开/收缩；单击未打开的库只选中，不自动打开。未打开库的图标为灰色，打开后为绿色。

以下操作主要介绍 MySQL/MariaDB 管理流程，其它引擎请阅读[原生查询及对象支持范围](database-engines.zh-CN.md)。

## 对象浏览与 DDL

双击数据库读取对象。单击表即选中并提供 DDL，由你手动切换右侧“DDL”标签查看；双击表打开数据标签。左侧改选其它表时，已经打开的工作标签不会自动被替换。

对象列表支持 Ctrl/Command 多选、Shift 连选、全选与鼠标框选；右键已选表保留多选。批量删除会先列出完整表名确认。点击空白处取消选择，空白处右键可新建表、导入导出、查看字典等。

关闭数据库会在必要的未保存确认后，关闭该库对应的数据、设计、查询和命令行标签；其它数据库及服务器连接保持打开。

## 编辑表数据

默认网格视图，分页信息后面的图标可切换表单视图。每页最多 1,000 条，滚动采用虚拟渲染。拖动表头分隔线调整列宽，按连接/库/表记住宽度及可见列。

1. 单击选中，双击具体单元格进入编辑。
2. Enter 结束编辑，Shift+Enter 换行，Esc 取消当前单元格修改；结束编辑仅更新草稿。
3. 点击“保存”才写库；“新增”追加记录，“删除”删除选中记录。Tab/Shift+Tab 逐项切换可编辑字段。
4. 单元格右键可复制完整原值、复制为 SQL/制表符文本、设为空白字符串/NULL、生成 UUID 或刷新。复制的 SQL 不会自动执行。
5. “单元格编辑器”或编辑单元格中的“…”提供完整文本、日期时间和 JSON/HEX 等类型快捷操作。

修改已有记录需要主键或可用的非空唯一键及原始快照；无此键时已有记录只读，仍可新增。BIGINT/DECIMAL 保留文本精度，不转成有舍入风险的 JavaScript 数字。空间值在数据编辑器中只读。

直连/SSH 的适用 InnoDB 表可“开始事务”，使用独立固定会话。事务内保存后仍需提交或回滚；PHP 中转暂不提供跨请求事务。回滚不能撤销已经提交的修改，也不能保证撤销非事务表或触发器的全部影响；报错或停止后请刷新核对服务器状态。

## 查询与命令行

“新建查询”在选中库下打开可关闭标签，可以执行选中 SQL 或全部 SQL。符合条件的直接字段单表 SELECT 结果共用数据编辑器，联表、聚合、表达式或来源不明确的结果只读。新增记录请进入源表。普通查询预览保留 1,000 行 / 8 MB 显示边界。

“命令行界面”打开主窗口标签，默认使用入口选中的数据库。分号结束后 Enter 执行，或 Ctrl+Enter 执行；Shift+Enter 换行，↑/↓ 历史，Ctrl+C 停止，Ctrl+L 清屏。支持 `help`、`clear`、`exit` 和单独的 `USE` / `\u`。结果摘要显示请求耗时，单位秒、两位小数；历史仅在内存，输出有明确显示限制。

这是 SQL 界面，不是系统终端。查询与命令行的每次提交使用独立会话；会话变量或完整事务应放在一次提交中，不应依赖跨次状态。

## 设计表

通过“新建表”或“设计表”打开设计标签，提供字段、索引、外键、触发器、选项、注释和 SQL 预览。下方属性随字段类型变化，文本字段提供可输入搜索的字符集与排序规则；新增文本字段先跟随库/表默认，已有定义保留真实设置。

新增字段可按常见名称建议类型与长度，手动设置优先。索引字段可勾选、排序、设置子部分长度和排序方向。网格列宽及下方属性区高度可拖动调整，不会使表结构草稿变脏。

保存直接执行，未命名新表先要求输入表名，删除设计项始终需要确认。保存后保持当前分类；服务器结构已变化时，设计器重新读取结构并停止旧 SQL 保存，保留先前草稿 SQL 供查看。DDL 可能部分完成；失败显示服务器详情，不承诺自动回滚。

## 导入导出与数据库工具

导入先选择格式、来源表/工作表及字段映射，再生成 SQL 预览，确认后才写入。导出打开系统另存为，并在后端流式读取全部记录，不设应用总行数/文件大小上限；格式本身及导入边界仍适用。详见[格式指南](data-transfer.zh-CN.md)。

“转储 SQL 文件”提供“结构和数据”与“仅结构”，另存为默认使用 `数据库名.sql`。内容包括表、视图及可选数据，不包含例程、事件和触发器，不能视作整个实例的完整备份。字典可导出 HTML，模型按真实键关系导出 SVG；这些是应用输出文件，项目指南仍使用 Markdown。

“运行 SQL 文件”执行已检查的 SQL 批次，删除数据库要求输入准确库名。关闭主窗口前会检查未保存草稿、查询及事务。
