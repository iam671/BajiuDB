The application UI is currently Simplified Chinese; English documentation includes UI labels where helpful. The current version is **0.0.1**. Windows x64 and experimental Linux/macOS packages are built; native Linux/macOS desktop execution remains unverified.

Developer records: [validation history](../VALIDATION.md), [UI check notes](../design-qa.md) and [implementation pitfalls](pitfalls.md). These existing working records are maintained in Chinese; they are separate from the bilingual user guides.
